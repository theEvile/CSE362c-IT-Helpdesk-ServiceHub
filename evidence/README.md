# Evidence collection

Add actual evidence as features are implemented. Do not invent screenshots or test results.

- ui/: Mobile/desktop rendering, keyboard checks, labeled forms.
- http/: HTTP requests, status codes and matching server responses.
- validation/: Positive/negative input tests and saved database records.
- quality/: Regression checks, browser compatibility and defect diagnosis.
- security/: Unauthorized action rejection and verified controls (after J3).
